# Valentine's Day Dinner Selection Page

This is a simple website created for Valentine's Day to let my girlfriend select her preferred dinner options for our special evening.

## Features
- Beautiful Valentine's Day-themed background.
- Easy-to-use dropdown menus for selecting:
  - Entrée options: Salmon Steak, Lobster Tail, Braised Short Ribs.
  - Side options: Mashed Potatoes, Baked Potatoes, Veggies, Rice.
  - Dessert options: Me, Crumbl Cookie, Fruit & Cheese Plate, Cake.
- User-friendly interface with instant notification of selections.

## How to Use
1. Visit the [live site here](https://your-username.github.io/valentines-dinner/).
2. Select your preferred entrée, side, and dessert from the dropdown menus.
3. Submit your choices to notify me instantly!
